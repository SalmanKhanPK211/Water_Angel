# Water Angel

Water Angel is an IoT-based Smart Water Tank Monitoring and Management System designed to automate household water storage while reducing water wastage and improving water quality monitoring.

## Current Status

🚧 This project is currently under development.

The initial version focuses on building the core embedded system using the ESP32 microcontroller.

### Current Features

- Water level measurement using an ultrasonic sensor
- Water quality monitoring using a TDS sensor
- Automatic water pump control
- LCD-based status display
- Wi-Fi configuration using Access Point mode
- Cloud connectivity with Supabase

### Upcoming Features

- Progressive Web Application (PWA)
- Offline-first operation
- Analytics dashboard
- Smart alert system
- Enhanced pump control logic

## Hardware

- ESP32 WROOM
- HC-SR04 Ultrasonic Sensor
- TDS Sensor
- Relay Module
- Water Pump
- 16×2 I2C LCD
- LEDs and Buzzer
